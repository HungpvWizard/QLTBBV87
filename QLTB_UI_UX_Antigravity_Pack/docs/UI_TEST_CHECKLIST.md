# UI TEST CHECKLIST

## Smoke
- Login/logout/session
- Main navigation/routes
- CRUD where applicable
- Search/filter/sort/pagination
- Upload/download/import/export
- Permission-specific visibility/actions
- Status transitions
- Error/loading/empty states

## Visual
- 1366x768
- 1920x1080
- Tablet/mobile if supported
- Long Vietnamese text
- Long equipment names/codes
- Empty/1 row/many rows

## Accessibility
- Tab order
- Visible focus
- Form labels/errors
- Modal keyboard behavior
- Icon button labels
- Contrast/status not color-only
